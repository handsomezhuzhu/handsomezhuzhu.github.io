# 再见了TRAE


####
##### 写在前面：
####

<span style="font-size:0.9em; color:#1976d2;">
&emsp;&emsp;我在 2025 年年初就正式接触 AI，包括 API 调用、本地部署之类的，虽然之前也用过文心一言。但真正开始体验 <span style="color: #43a047;">Agent 能力</span>，还得从 TRAE 说起。
</span>

<div align="center">

## 壹 · 初见

</div>

&emsp;&emsp;在我印象里，AI 编程这个话题讲了很多年了，包括 GPT-3 时代。那会儿有 Copilot，有通义灵码、文心快码，其实很难用，顶多就是<span style="color: #1976d2;">更智能的补全和代码问答</span>，能编辑一些片段或生成单个文件。

&emsp;&emsp;后来接触到了 [LINUX DO](https://linux.do) 这样的社区，了解到 TRAE 这类工具。那会儿是带着好奇去用的，因为对 AI 编程能力一无所知；也没有什么 MCP、Skills，不像现在，出个新的 Agent 工具，我都会带着期待去尝试。那会儿只知道能“辅助编程”，不过真的上手后就彻底打脸了。TRAE 真的能 <span style="color: #43a047;">Vibe Coding</span> 了。索性我就纯用 TRAE，接上豆包模型做了一个[小工具](https://github.com/handsomezhuzhu/English-words)。

&emsp;&emsp;那会儿 AI 的项目能力其实很一般，只能靠仅有的一点上下文记忆，一个接一个地生成文件；虽然也会调用工具、执行命令，但是经常卡死，似乎是执行结束后，TRAE 没法重新拉起模型请求。这个项目里面我甚至还加入了 AI API 翻译功能 ~~本人首个 AI Agent 项目~~。

<div align="center">


## 贰 · 转折

</div>

&emsp;&emsp;之后就是 Copilot 复出，Codex、Claude Code 出圈，TRAE 由于模型能力的限制，开始慢慢淡出我的视野。再后来，它开始推出 SOLO 模式，其实这个就真正摆脱了 <span style="color: #1976d2;">IDE 的束缚</span>，开始纯 Vibe Coding 时代了：仅用自然语言就能生成所有代码、完成所有测试。同时期，市面上大部分 AI 编程工具都开始摆脱 IDE，走向智能体的行列。


<div align="center">


## 叁 · 终章

</div>
&emsp;&emsp;但是站在今天，回望 TRAE 的发展过程，其实一直是围绕程序员群体在转。因为程序员一直是最先开始使用 AI 工具的，之后才是极客爱好者，最终就是<span style="color: #1976d2;">普罗大众</span>。

&emsp;&emsp;今天，[TRAE 宣布 TRAE 账号自 2026 年 11 月 18 日起将自动升级为豆包飞书账号](https://docs.trae.cn/ide_important-notice-for-trae-account-upgrade-and-integration)。我想原因很简单，AI Agent 最终是<span style="color: #43a047;">所有人都可以用上的生产力工具</span>，不能仅局限于 Vibe Coding，写个网页、写个项目，而是要成为能帮助到每个人的智能助理。

&emsp;&emsp;早在 2026 年，ChatGPT 就宣布将 AI 编程 CLI 工具 Codex 整合进 ChatGPT 桌面端。目前 ChatGPT 已经几乎看不到只为程序员服务的一面了，桌面端能处理工作，网页端的 WORK 能随时随地布置任务给 AI。

&emsp;&emsp;今年，豆包工作、WorkBuddy、Qoder、Grok Bot、Muse 这些产品扎堆出来，路其实越来越清楚了：<span style="color: #1976d2;">程序员这边从 AI IDE 走向 ADE</span>，面向大众这边则从对话式助手走向真正能做事的 Agent。很多时候，你已经不 care AI 写了什么、运行了什么，只关心最后事情办没办成。或许这就是今后 Agent 的最终形态。

&emsp;&emsp;说实话我一直很抵触什么 WorkBuddy、什么豆包工作，我觉得<span style="color: #d32f2f;">土死了，垃圾死了</span>。我钟爱 <span style="color: #43a047;">OpenCode</span>，钟爱 <span style="color: #43a047;">[Orca](https://www.onorca.dev/)</span>，但是事实就摆在面前：AI 早已不是程序员和极客的独享，AI 就应该<span style="color: #1976d2;">“飞入寻常百姓家”</span>。
