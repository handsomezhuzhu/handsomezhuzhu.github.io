# [Orca](https://www.onorca.dev/)：vibe coding最后的倔强

####
##### 写在前面：
####

&emsp;&emsp;<span style="font-size:0.9em; color:#1976d2;">前一篇[《再见了TRAE》](/sop/tech/goodbye-trae.html)提到过，TRAE 现在已经不只是围着 AI IDE 打转了，Codex 也被整合进了 ChatGPT 桌面端。大众这边 WorkBuddy 还在帮你处理对话里的工作，Grok Bot、Muse 已经开始让 Agent 在云端接着帮你干活。</span>

<div align="center">

## 壹

</div>

&emsp;&emsp;程序员最早是 Copilot 在编辑器里补两行，后来是 Cursor、TRAE 这类 AI IDE，再后来 Claude Code、Codex 这些 Agent 直接接命令、改文件。ChatGPT 原本就是聊天框，现在都开始往云端 Agent 发展了。


&emsp;&emsp;Grok Bot 和 Muse 最有代表性的地方，就是它们不只跟你聊。它们能有自己的云端电脑，能打开浏览器、处理文件，让任务继续跑。你不用关心它点开了几个网页、读了多少资料，最后告诉你办没办完就行。

&emsp;&emsp;那程序员呢？<span style="color: #d32f2f;">或许 [Orca](https://www.onorca.dev/) 才是最后的倔强。</span>

<div align="center">

## 贰

</div>

&emsp;&emsp;[Orca](https://www.onorca.dev/) 把自己叫做 <span style="color: #43a047;">ADE（Agent Development Environment）</span>。以前我们更关心“这个文件写到哪里了”，现在越来越多的是“这个任务跑到哪了、改出了什么问题、能不能用”。


&emsp;&emsp;现在程序员更向往<span style="color: #43a047;">多 Agent 并行</span>。Claude Code、Codex、OpenCode，甚至其他能在终端里跑起来的 CLI Agent，都可以接进来。[Orca](https://www.onorca.dev/) 给了你一套工作台，把这些 Agent 聚在了一起。

&emsp;&emsp;你可以让不同 Agent 分别处理不同任务，也可以让它们各做一版，再自己看看谁写得更像回事。每个任务放在独立的 Git worktree 里，各自改各自的文件，各干各的活。


<div align="center">

## 叁

</div>

&emsp;&emsp;大众工具让人不用管实现过程，这是非常合理的。可写软件不完全是这么回事。网页打开了、测试跑过了，不代表代码以后还能维护。AI 说“搞定了”，最后真出 Bug，还是你来收拾。所以 Vibe Coding 也不能只剩<span style="color: #1976d2;">“感觉能跑”</span>，总得有地方让你看改动、跑验证、做取舍。

&emsp;&emsp;这就是我喜欢 [Orca](https://www.onorca.dev/) 的地方。它没有把代码藏起来，假装以后大家都不需要关心了；反而把 Agent 的过程和结果摆在你面前。过去 AI IDE 代码在中间，AI 在右侧，但是现在 [Orca](https://www.onorca.dev/) 里 AI 在中间，代码和终端在右侧。所以“最后的倔强”不是说 [Orca](https://www.onorca.dev/) 反潮流，更不是坚持让程序员回去手写所有代码。

&emsp;&emsp;AI 面向大众肯定是大势所趋，Grok Bot、Muse 这样的产品也只会越来越多。以后大家可能都有自己的 Agent，帮忙处理生活、工作里那些琐碎又重复的事情。AI 本来就应该“飞入寻常百姓家”。

&emsp;&emsp;但我还是希望，有一个工具愿意继续把程序员的工作流做好。不是告诉我“你不用看代码”，而是让我能更轻松地交代任务、看懂改动、选一个好结果，最后把一个项目交付出去。

&emsp;&emsp;也许 ADE 后面还会变成别的样子，但至少现在，[Orca](https://www.onorca.dev/) 让我看到了 Vibe Coding 除了“AI 写、随 AI 跑”之外，有了一种更靠谱的方式。
