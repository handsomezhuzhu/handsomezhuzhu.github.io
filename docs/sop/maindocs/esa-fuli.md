# 【热推福利】ESA基础版发放中 | 发帖分享即可领

::: details 什么是阿里云 ESA

<span style="font-size:0.9em;">阿里云 ESA（Edge Security Acceleration，边缘安全加速）是集 CDN 加速、边缘安全防护、边缘计算和 HTTPS 管理于一体的边缘云服务。相比传统 CDN，ESA 在国内节点覆盖、边缘安全能力、易用性和前端部署（ESA Pages）上都有更出色的体验，是面向国内用户业务的省心之选。</span>

:::

阿里云 ESA 正在发放基础版福利：**只需在社交平台发帖推荐 ESA，每 14 天即可领取 1 次 1 个月 ESA 基础版兑换码**，所有用户均可参加，不限次数！

> 活动时间以阿里云官方页面为准，请确保发帖前已完成账号认证。

## 活动规则

- 在社交平台或论坛博客发布一篇使用阿里云 ESA 的帖子；
- 每 14 天可领取 1 次 1 个月 ESA 基础版兑换码；
- 所有用户均可参加，**不限次数**；
- 参加活动前需完成账号认证。

## 发帖要求

支持的平台包括但不限于：Linux.do、V2EX.com、X.com、掘金、知乎、小红书、B 站、个人博客、facebook.com、youtube.com 等。纯文字、图文、视频形式均可。

| 要求 | 说明 |
| --- | --- |
| 突出 ESA 优势 | 说出至少 1 个 ESA 比同类产品更好的地方，例如边缘安全加速、CDN、ESA Pages、HTTPS、缓存、安全防护、前端部署等方面 |
| 带上关键词 | 内容中需包含 `#阿里云ESA` 和 `#边缘安全加速` 关键词 |
| 字数要求 | 图文帖子不少于 80 字；视频需在标题、简介或评论区体现 ESA 相关信息 |

## 为什么推荐 ESA

作为经常折腾域名、网站、博客和小项目的人，真心觉得[阿里云 ESA](http://s.tb.cn/e6.0Fu67m) 在国内体验上非常省心。它依托阿里国内节点，延迟低、丢包少，而且把安全、加速、部署整合在一张网络里，不用像传统方案那样配来配去。面向国内访问的业务，ESA 确实是稳且省事的选择。
